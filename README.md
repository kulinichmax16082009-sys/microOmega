# 2048 Remake
This is a 2D remake of the popular web game 2048. The remake was developed in the Java programming language using the IntelliJ IDEA IDE. The game uses JFrame and JPanel to make a better gaming experience.

## Features
* The game can be saved and loaded.
* Use W, A, S, and D keys to move the cells.
* The game board consists of a 4 × 4 grid.
* The player's score and time are updated after each move.
* The player wins when a cell with the value 2048 is appeared; otherwise, the game ends when no more moves are possible.
* The game can be closed at any stage.

## Controls
* **W or ↑**: Move all cells up
* **S or ↓**: Move all cells down
* **A or ←**: Move all cells left
* **D or →**: Move all cells right
* **Ctrl + S**: Save the current game state
  
## How to run
**for running .jar file you need:**
1) Create a folder with random name (ex. game)
2) Put .jar file and resources folder in folder you have just created
3) Go to your folder in Terminal by using: **`cd (folder-path)`**
4) To run the program enter: **`java -jar (file-name.jar)`**

## Requirements
* download JDK 17 or greater
* download [Windows Terminal app](https://apps.microsoft.com/detail/9n0dx20hk701?hl=ru-RU&gl=CZ) from Microsoft Store
